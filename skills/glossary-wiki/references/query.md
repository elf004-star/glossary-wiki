# 检索

1. 从当前目录最近的 wiki 开始，读取 index、术语表与覆盖状态。使用规范名、别名检索对应页面，必要时沿父 index 查本项目其他子 wiki。局部找到足够证据即回答。
2. 本项目证据不足时，读取全局 catalog（`CATALOG_ROOT`）的分类路由，按术语及摘要查相关项目，再打开其真实 index 与权威页面。明确注明哪些结论来自其他项目；同名异义按 project_id 分开解释，不能移植成当前项目规则。
3. 引用可点击的 wiki 页与原始来源，区分事实、推断和资料缺口。检查使用页面的来源状态；Hashdeep 表明原文改变时说明知识过期，必要时走增量摄取。未改变原文可使用已编译内容；用户要求逐字验证引用时可按需回看原文并说明目的。
4. 失效路径按 tools.md 查找；找不到或权限不足即报告覆盖缺口。搜索无结果不能证明所有未摄取资料也无答案。
5. 用户要求沉淀时，把有来源的新综合结论存为页面，更新索引、依赖和日志；事实源摘要未变时不需要重读原文。普通问答保持只读。

完成条件：每个确定性结论都有可访问证据，跨项目口径明确标注，未知部分直接说明；不为补全答案杜撰定义。
